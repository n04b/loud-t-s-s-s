How loudTSSS works

loudTSSS keeps an app's environment config in one JSON file. The schema (variable names, types and metadata) is plain text in git. The values live in one AES-256-GCM block per environment, encrypted with that environment's key. This page runs the MVP workflow in your browser with real encryption (Web Crypto); nothing leaves the page.

Click a step: it runs against the files below and lights up its path. Then try to break it.

Web Crypto is not available in this browser context, so the sandbox is hidden; the steps above still explain each command. Open the file directly (file://) or over https in a current Chrome, Firefox or Safari.

The file layout follows the MVP scope in TODO.md: a JSON config, environments as a record with protected, symmetric keys, blocks inline in git. The exact shape of the working file and of a block's plaintext (version, values, meta) is illustrative. In the demo every key is generated in memory when the page loads, and CI is assumed to hold the keys of all environments.
